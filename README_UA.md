# Скелет сайту каталогу кондиціонерів

Це перший каркас сайту без адмінки: головна, каталог, сторінки брендів, сторінка товару, інформаційні сторінки, попап заявки, базова обробка заявок.

## Структура

- `/` — головна
- `/catalog` — каталог всіх товарів
- `/brand/tcl` — бренд TCL
- `/brand/hisense` — бренд Hisense
- `/brand/skylux` — бренд SkyLux
- `/product/nazva-tovaru` — сторінка товару
- `/payment-delivery` — оплата і доставка
- `/warranty-return` — гарантія та повернення
- `/public-offer` — публічна оферта
- `/privacy-policy` — політика конфіденційності
- `/contacts` — контакти

## Як завантажити на хостинг

1. Розпакувати архів.
2. Завантажити всі файли в папку сайту, наприклад `/www/iceklimat.com/`.
3. У `config.php` змінити:
   - назву сайту;
   - телефон;
   - email;
   - `import_key`;
   - Telegram token/chat ID, коли будемо підключати Telegram.

## Важливо

Папки `/storage/` і `/data/` закриті через `.htaccess`, щоб заявки та файл товарів не відкривались напряму в браузері.

## Що ще не реалізовано

Імпорт Excel поки зроблено як службову заготовку. Наступний крок — підключити читання `data/products.xlsx`, завантаження фото в `/uploads/products/` і формування `/storage/products.json`.
